How do I get my files from Google Drive?
  1. Open drive.google.com in Chrome (on the phone, choose Desktop site).
  2. Right-click your folder and choose Download. Google prepares a .zip file.
  3. Come back here, tap Import a Google Drive .zip and pick that file.
  4. Your folders and files appear here and work with no internet.
Repeat this whenever you add new work to Drive.

How do I get a Client ID? (one-time, about 5 minutes)
  1. Open Google Cloud Console, create a project, and turn on the Google Drive API.
  2. Under OAuth consent screen choose External and add your own Google account as a Test user.
  3. Under Credentials create an OAuth client ID of type Web application. Add the web address where this app is hosted as an Authorized JavaScript origin.
  4. Copy the Client ID here, press Sign in, then Choose Drive folder and Sync now.
Sync only reads your Drive (it never changes it) and needs internet while syncing. It works only from the hosted https address, not from a file on your phone.
